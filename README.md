# Aditya — Java Full Stack Developer Portfolio

Responsive personal portfolio built with React, TypeScript, Vite and Tailwind CSS.

## Requirements
- Node.js 18+ (Node.js 20 LTS or newer recommended)
- npm
- Visual Studio Code

## Run locally
1. Extract this ZIP and open the `aditya-java-full-stack-portfolio` folder in VS Code.
2. Open **Terminal → New Terminal**.
3. Install dependencies: `npm install`
4. Start the dev server: `npm run dev`
5. Open the local URL shown in the terminal (usually http://localhost:5173).

## Production build
`npm run build` then `npm run preview`.

## Project structure
- `src/App.tsx` — portfolio sections and content
- `src/index.css` — responsive styling and editorial hero
- `public/resources/aditya-profile.png` — latest profile portrait

Featured projects: E-Commerce Website, Employee Management System, Employee Payroll System.
